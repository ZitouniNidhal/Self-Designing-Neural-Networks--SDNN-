# ArchitectAI Documentation

Welcome to the official documentation for **ArchitectAI (Self-Designing Neural Networks - SDNN)**.

ArchitectAI is an open-source framework for autonomous neural network design, evolutionary architecture search (NAS), hardware-constrained optimization, and multi-framework code generation.
